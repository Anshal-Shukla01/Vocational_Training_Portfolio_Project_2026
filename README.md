## 📖 About the Project

This project is a personal portfolio website built as part of my vocational training. It is a single-page website made using **HTML5** and **CSS3** to showcase my introduction, skills, projects, and certificates.

The goal of this assignment was to practice front-end web development concepts such as semantic HTML, CSS styling, responsive design, and basic UI layout using only HTML and CSS (no frameworks or JavaScript).

## 🎯 Objective

- ✅ To apply HTML and CSS concepts learned during training in a real project
- ✅ To build a responsive website that works on both desktop and mobile
- ✅ To design a clean and organized personal portfolio page
- ✅ To practice structuring a webpage using multiple sections
